**Veridian — Leakage-Safe Heterogeneous Stacking for Multi-City AQI Forecasting**  
*Research manuscript · Publication in progress*

Investigated chronological AQI forecasting across six Indian cities using XGBoost, Extra Trees, Bi-LSTM, Bi-GRU, Temporal Convolutional Networks, and heterogeneous stacking.

The experiments demonstrated that the strongest standalone XGBoost model (RMSE: 28.10) outperformed both evaluated stacked ensembles, highlighting the importance of predictive complementarity and leakage-aware evaluation.
